### Transaction construction (reviewed, not changed)

- **Min-out / slippage:** `swapFloorViolation` + `assertActionPolicy` on pure Alcor swaps; `MAX_SLIPPAGE_PCT = 3`; dust rewrites min-out to 1 raw unit (documented, size-bounded).
- **Fee:** `platformFeeOn` floors at token precision, skips zero units, recipient `smart.ass`, canonical memo. Same atomic tx as the swap(s). Tests in `platform-fee.test.ts`.
- **Arb floor:** `arbFloorViolation` uses on-chain sell min-outs. Fee is added onto `quoteIn` before the floor check — slightly **tighter** than “stake × (1+p) + fee”, not weaker. Comment in `sign.ts` is conservative, not a bug.
- **Atomicity:** fee + swap legs packed in one `signAndPushTransfers`. Revert reverts the fee.
- **Simulation:** session-key path simulates when nodes answer; `auto` proceeds if simulators are down (min-outs still on-chain). WCW/Anchor not simulated (documented).

### RPC / failover (reviewed)

Health-scored pool, chain-id check, cooldown/restore. `push_transaction` is not sent through the CORS read proxy. Custom endpoints remain a user-trust feature (warning copy added on the Infra desk).

### XSS / CSP (reviewed)

No `dangerouslySetInnerHTML` / `eval` / `new Function` in `src/`. Telegram vendor `innerHTML` is origin-gated to `web.telegram.org`. CSP report sink: `api/csp-report.ts` (rate-limited, 204).
